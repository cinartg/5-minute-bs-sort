# 5-minute-bs-sort
a "bubble sort-like" sort that i created quite literally in just a few minutes, as the name suggests. it is VERY inefficient and crappy, but just goes to show how far practice can take one. the "bs" does *not* stand for "bubble sort", by the way ;) 

---
# overview

it is pretty much your standard algorithmic Python file, the sorting itself is not particularly efficient or interesting. i believe that the time complexity is close enough to $O(n^2)$, so i just labeled it as it is, so please take it with a grain of salt. feel free to swap out the list for a list of any number of integers; but do be warned as i have stated before this algorithm is HIGHLY inefficient and redundant.
